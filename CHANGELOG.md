# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-07

### Added
- Expense management (add, edit, delete, search, and view expenses)
- Monthly budget management
- Finance dashboard with spending statistics
- Category-wise spending summary
- Monthly reports
- Category pie chart visualization
- Monthly bar chart visualization
- CSV and JSON data storage
- Backup and restore functionality
- Input validation for expenses and budgets

### Improved
- Enhanced dashboard layout and formatting
- Better error handling and input validation
- Improved documentation and project structure

### Fixed

- Applied Black formatting across the project
- Fixed dashboard indentation and formatting
- Corrected validation behavior to satisfy all unit tests
- Addressed datetime-related warnings
